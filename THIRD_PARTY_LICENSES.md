# Third-party software

The application is designed to install these packages locally through npm. No CDN is used at runtime.

| Package | Purpose | License |
|---|---|---|
| React | User interface | MIT |
| React DOM | Browser rendering | MIT |
| Vite | Development and production build | MIT |
| @vitejs/plugin-react | React JSX integration | MIT |
| Bootstrap | Responsive UI primitives | MIT |
| Bootstrap Icons | Local icon font | MIT |

Review the exact package versions and their bundled license files after running `npm install` before redistributing a binary package.
